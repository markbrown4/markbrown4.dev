Thanks to AI, anyone can build software now. I know this because I just built an app called Rituals, for iOS and Android, in a few hours a night over two weeks.

Three years ago, if someone had shown me this app, I would have been thoroughly impressed. In 2026, it's unimpressive software. Anyone with a Claude Code subscription and an idea could build it.

<!-- more -->

## What I built in two weeks of evenings

Rituals isn't a toy demo. Under the hood, it has everything I'd expect from a professional product:

- High-quality native iOS and Android apps
- A GraphQL API on an Elixir backend
- Thorough testing
- Infrastructure defined in Terraform
- A CI/CD pipeline shipping pre-release and production builds to the App Store and Google Play
- Database backups
- A marketing website

And the app itself has a real feature set:

- Email verification and sign-in with passkeys
- Creating your own rituals
- Automations with HealthKit on iOS and Health Connect on Android
- Challenges with increasing step counts
- Insights and suggested rituals
- Home-screen widgets on both platforms
- Dark mode
- Push notifications and deep links

## Fast, cheap, and good

The old rule was that you could pick two: fast, cheap, or good. Rituals was fast and cheap to build. But from where I stand, it also has all the hallmarks of quality software.

That's what makes it unimpressive. Not that it's bad, but that it's no longer rare. What once took a team months is now a side project for one person after dinner.

## So what should we build?

If software itself is now low value, where should we spend our time?

Software is valuable where it saves people time, money,  or brings enjoyment, . It's valuable when it delivers real-world utility or a service, the way Uber or Airbnb connect software to something physical. The app is only the front door; the value is in what happens in the world.

## Code is a commodity

Personal assistants and agents are so good now that a whole class of software doesn't need to be made in advance at all. It can be built on demand, when someone asks for it.

That creates a new problem: attention. When anyone can ship an app, it gets harder to convince people to even try yours. Some will tune out the moment they hear it was built with AI. Code is a commodity, and commodities don't get a second look.

## Existential dread, or excitement?

Honestly, it's a bit of both.

Many of the skills and experience I've built up over the years have largely been replaced by AI. No one needs me to write software anymore. No one needs specialist knowledge to build something. Anyone can build.

And yet I'm amazed by what these tools can create. Building Rituals hasn't made me feel smaller; it's made me more ambitious. Knowing what's possible now, I want to take on bigger projects. If impressive software is now unimpressive, the only answer is to aim higher.
